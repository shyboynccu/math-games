# Math Games

目前包含：**平方數 20 連戰**。

玩家需要依序完成 11～30 的平方數，題目會隨機且不重複出現。

## 線上遊玩

啟用 GitHub Pages 後，網址會是：

`https://shyboynccu.github.io/math-games/`

## GitHub Pages 設定

1. 開啟 repository 的 **Settings**。
2. 進入 **Pages**。
3. 在 **Build and deployment** 將 Source 設為 **Deploy from a branch**。
4. Branch 選擇 **main**，資料夾選擇 **/(root)**。
5. 按 **Save**。
